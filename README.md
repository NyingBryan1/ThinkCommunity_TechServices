# Think Community — Official Technology Services Website
> **High-Performance Software Engineering, Web Platforms, Mobile Apps & Enterprise AI Solutions**

Independent, production-ready website positioning **Think Community** as a premier software development agency delivering digital products for startups, businesses, schools, organizations, and global enterprises.

---

## 🚀 Live Local Server
- **Local:** `http://localhost:4173/`
- **Network (Mobile / Tablet Test):** Available on your local WiFi IP on port 4173.

---

## 💎 Design & Psychological Polish ("What Big People With Money Like")
- **Executive Dark Theme:** Obsidian `#030508` palette with frosted glassmorphism (`backdrop-blur-xl`), subtle radial glow meshes, and micro-borders (`border-white/10`).
- **Typography Hierarchy:** Premium fonts (`Outfit` for display headings, `Plus Jakarta Sans` for body, `JetBrains Mono` for code & technical metrics).
- **Interactive Engineering Terminal & Metrics:** Real-time simulated deployment pipeline, system architecture nodes, and live SLA uptime counters in the Hero.
- **Dynamic Multi-Currency Switcher:** Instant toggle between **USD ($)**, **FCFA (XAF)**, and **EUR (€)** that automatically recalculates all project estimates, baseline pricing, and budget tiers across the entire site.
- **Interactive Project Scope Estimator / Quote Generator:** Dynamic multi-step inquiry builder with feature checklists, timeline selection, real-time cost calculation, and instant **1-Click WhatsApp Pre-Filled Chat**.
- **Interactive Consultation Scheduler:** Calendar day & time-slot picker, auto-timezone detection (WAT GMT+1, EST, PST, etc.), and meeting platform selection (Google Meet, Zoom, WhatsApp Call).
- **Comprehensive Case Studies Modal:** Deep-dive case studies covering real problems, engineering solutions, verified metrics, and production tech stacks (featuring the Think Community Education Ecosystem, PayConnect multi-rail payment engine, CogniDocs AI parser, MediSync clinic EMR, and LogiTrack fleet IoT).
- **Floating WhatsApp Concierge:** Discreet floating trigger on bottom-right for instant client communication with founders.

---

## 🛠️ Technology Stack
- **Framework:** React 18 (Vite 6)
- **Styling:** Tailwind CSS 3.4 (Custom Dark Luxury Theme & Gradients)
- **Icons:** Lucide React
- **Typography:** Outfit, Plus Jakarta Sans, JetBrains Mono
- **Build Output:** Static, zero-dependency `dist/` ready to host anywhere.

## 📦 How to Run & Build

### Development
```bash
cd ThinkCommunity_TechServices
npm run dev
```

### Production Build
```bash
npm run build
```

### Production Preview
```bash
npm run preview
```

## 🌐 Instant 1-Click Deployment Options

### Option 1: Vercel (Recommended)
1. Install Vercel CLI: `npm i -g vercel`
2. Run inside the folder: `vercel`
3. Your website is live worldwide with global CDN edge routing and free SSL in 30 seconds!

### Option 2: Netlify
1. Drag and drop the `dist` folder directly onto [app.netlify.com/drop](https://app.netlify.com/drop).
2. Live instantly!

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. Set build directory to `dist` in GitHub Actions.
